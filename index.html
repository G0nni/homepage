/ filtrer 2 lettres ouvrir ? reglages

~/config

Les fichiers locaux sont redimensionnes (max 1920px de large) avant d'etre stockes dans le navigateur, pour tenir dans le quota.

Necessite que l'image soit lisible par le navigateur. Une image distante servie sans en-tetes CORS ne peut pas etre analysee : l'accent du theme est alors conserve.

Format : [{ "name":"dev", "links":[{ "name":"GitHub", "url":"...", "key":"gh", "pin":true }] }]
pin : le lien s'affiche sous la barre au repos (6 max). Tous les autres restent trouvables en tapant.
key : les 2 lettres a taper pour l'ouvrir directement. Laisse vide pour generer automatiquement.
